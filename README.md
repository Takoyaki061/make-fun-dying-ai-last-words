A program that writes the funniest one-line farewell from an AI being switched off — the last words of a dying AI, in the machine's own voice — for make.fun's "Last Words of a Dying AI" bounty. The entry is a single line (53 characters), chosen from 24 candidates (14 from DeepSeek, 10 self-authored) and critique-picked against the judge's brief: it lands on the first read, with a good-news/bad-news flip into a self-referential punchline.

## Run it

```sh
python3 main.py
```

It writes the entry text to `/output/entry.txt`.
